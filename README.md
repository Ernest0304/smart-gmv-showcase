# Smart GMV — case study

A shared-kitchen operator's nightly delivery-sales round, rebuilt as a phone-first app: staff
photograph each platform's summary screen, a vision model reads the figures, the person on shift
confirms them, and the row is filed with the photo kept as evidence.

**Live page:** https://ernest0304.github.io/smart-gmv-showcase/

Single file, no build step, no external requests. The demo runs entirely in the browser.

Every kitchen, brand and figure on the page is invented. No licensee, staff or revenue data
appears anywhere — the performance figures describe the system, not any customer's business.

Ernest Heng · Operations Manager · Singapore
